# RSA Encryption/Decryption Tool

Инструмент командной строки для шифрования и дешифрования RSA, реализованный на Go. Предоставляет простой интерфейс для генерации RSA-ключей, шифрования сообщений и дешифрования зашифрованных данных.

## Функциональность

- **Генерация RSA-ключей**: Создание новых пар открытого/закрытого ключей с настраиваемыми параметрами
- **Сохранение/Загрузка ключей**: Сохранение сгенерированных ключей в файлы или загрузка существующих
- **Шифрование данных**: Шифрование текста из `input.txt` с использованием загруженного открытого ключа
- **Дешифрование данных**: Дешифрование зашифрованных данных из `input.txt` с использованием закрытого ключа
- **Управление файлами**: Автоматическая обработка входных/выходных файлов
- **Отображение статуса**: Просмотр текущего состояния ключей и файлов

## Требования

- Go 1.25 или выше
- Пакет [godotenv](https://github.com/joho/godotenv)

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/nikitavaulin/rsa-golang.git
   cd rsa-golang
   ```

2. Установите зависимости:
   ```bash
   go mod download
   ```

3. Соберите приложение:
   ```bash
   go build -o rsa-tool cmd/rsa/main.go
   ```

## Использование

Запустите приложение:
```bash
./rsa-tool
```

### Основное меню

1. **Сгенерировать новую пару ключей**: Создает новую пару RSA-ключей. Можно сохранить их в файлы.
2. **Загрузить ключи из файлов**: Загружает существующие ключи из `key_public.txt` и `key_secret.txt`
3. **Зашифровать данные**: Шифрует содержимое `input.txt` с использованием загруженного открытого ключа
4. **Расшифровать данные**: Дешифрует содержимое `input.txt` с использованием закрытого ключа
5. **Сохранить текущие ключи в файлы**: Сохраняет загруженные ключи в файлы
6. **Показать текущий статус**: Отображает информацию о загруженных ключах и файлах
0. **Выход**: Завершить работу приложения

### Файлы

- `input.txt`: Содержит открытый текст для шифрования или зашифрованные данные для дешифрования
- `output.txt`: Содержит зашифрованные данные или расшифрованный текст
- `key_public.txt`: Файл открытого ключа (e,n)
- `key_secret.txt`: Файл закрытого ключа (d,n)

## Конфигурация

Вы можете настроить параметры RSA, создав файл `.env` на основе `.env.example`:

```
p=    # Простое число P
q=    # Простое число Q
e=    # Открытая экспонента (по умолчанию: 65537)
```

Если файл `.env` отсутствует, система автоматически сгенерирует случайные простые числа.

## Формат ключей

### Формат открытого ключа
```
E: <экспонента>
N: <модуль>
```

### Формат закрытого ключа
```
D: <секретная экспонента>
N: <модуль>
```
